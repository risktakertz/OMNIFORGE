# astro-business template

Content-first business site starter on **Astro 5** — zero client JS by default,
ideal for SEO-driven local business and portfolio sites. Use it (instead of the
zero-dependency static template) when the product needs content collections,
MDX, or component-driven pages.

```bash
npm install
npm run dev      # http://localhost:4321
npm test         # structural checks (no install needed)
npm run build    # static output in dist/ (needs deps installed)
```

Builds are verified by the integration CI workflow on demand (to conserve
routine CI minutes), not on every push.
