# Product discovery skill

Produce: target user, problem, smallest sellable MVP, explicit non-goals, risks, cost hypotheses (clearly labeled estimates — never fabricated demand). Map the MVP onto blueprint scope (mvp/later/excluded). Keep it short; the blueprint engine formalizes it.
